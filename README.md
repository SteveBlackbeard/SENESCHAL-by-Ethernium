Seneschal picks the files instead. **69,412 tokens down to 8,236 — measured, not estimated.** It also scans what you feed a model for prompt injection, and enforces what an agent may touch with grants it cannot forge.

Zero runtime dependencies. Nothing leaves your machine.

```bash
pip install seneschal
seneschal select --path . --objective "fix the login flow" --max-tokens 8000
```
